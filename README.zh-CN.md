# alatticeio/homebrew-tap

由 [alatticeio](https://github.com/alatticeio) 维护的 macOS 软件 Homebrew 源。

## 前提条件

你需要先安装 [Homebrew](https://brew.sh)。如果尚未安装，请运行：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## 添加此源

```bash
brew tap alatticeio/tap
```

## 如何安装

添加源之后，使用以下命令安装软件：

```bash
brew install alatticeio/tap/<软件名>
```

## 更新

保持已安装软件为最新版本：

```bash
brew update && brew upgrade
```
