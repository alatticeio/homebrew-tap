# alatticeio/homebrew-tap

A Homebrew tap for macOS software distributed by [alatticeio](https://github.com/alatticeio).

## Prerequisites

You need [Homebrew](https://brew.sh) installed. If you don't have it yet:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## Add This Tap

```bash
brew tap alatticeio/tap
```
